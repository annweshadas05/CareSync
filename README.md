# -CareSync--Patient-Service-Management-Web-Application-
CareSync is a patient service management web application that connects patients, doctors, and administrators on a single digital platform. It streamlines appointment scheduling, patient records, and healthcare communication with secure, role-based access.

## Features
- Patient management
- Doctor management
- Appointment scheduling
- Reports handling
- Role-based dashboards

## Tech Stack
- PHP
- MySQL
- HTML, CSS, JavaScript
- XAMPP

## Setup
1. Import `caresync.sql` into MySQL
2. Run project using XAMPP (htdocs)
3. Open `localhost/CareSync`
